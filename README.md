# NASA APOD Wallpaper

![NASA APOD](https://apod.nasa.gov/apod/image/2603/cg4_1024.jpg)

## What it does

- Downloads NASA's Astronomy Picture of the Day every day.
- Sets it as your Mac desktop wallpaper.
- Uses saved pictures if today's post is a video or offline.

## How to install

1. Get a free API key at [api.nasa.gov](https://api.nasa.gov/).
2. Run setup:

```bash
./setup.sh
```

Enter your API key when prompted to turn on daily updates.
